Currículo Adaptável — Otimizador ATS

Cadastre sua trajetória uma vez. A cada vaga nova, cole a descrição e receba um currículo adaptado, com crítica de recrutador e checklist ATS.

Seu arquivo de dados

Pense nisso como um documento seu: abra o arquivo, edite o que precisar nas seções abaixo e clique em "Salvar" para gravar direto nesse mesmo arquivo — sem downloads repetidos. Da primeira vez, clique em "Salvar" para criar o arquivo; nas próximas vezes, abra esse mesmo arquivo para continuar de onde parou.

Meu navegador não deixa "salvar direto" / prefiro baixar e importar manualmente

Alguns navegadores (Firefox, Safari) não suportam salvar direto no arquivo. Use as opções abaixo como alternativa:

Importar de um currículo existente (PDF ou Word)

O app consegue extrair o texto de um PDF ou .docx direto no navegador (nada é enviado para nenhum servidor). Ele preenche automaticamente apenas contato (nome, e-mail, telefone, LinkedIn) — resumo, habilidades e experiências você cola manualmente nos campos certos a partir do texto extraído, porque cada currículo tem um formato diferente e um preenchimento 100% automático arriscaria inventar ou embaralhar informação. Alternativa mais rápida: anexe o currículo diretamente na conversa com o Claude e peça para gerar o arquivo .json pronto — como o Claude entende o conteúdo, ele monta a estrutura completa (experiências, bullets, tags) de uma vez, sem esse trabalho manual.

Contato

Resumo profissional (base)

Um resumo geral, "verdade universal" sobre sua carreira. O app vai gerar uma versão adaptada para cada vaga a partir disso — não precisa ser perfeito aqui.

Habilidades / competências

Adicione todas as habilidades que você realmente domina, organizadas por categoria (ex.: "Comércio Exterior", "Sistemas e Ferramentas", "Comportamentais") — assim o currículo gerado sai agrupado como num currículo profissional de verdade, e não uma lista solta. O app vai priorizar dentro de cada categoria o que a vaga pedir — nunca inclua algo que você não sabe fazer de verdade.

Os dois campos abaixo têm sugestões (clique na setinha ou comece a digitar) — mas você pode digitar qualquer coisa que não esteja na lista.

Experiência profissional

Cadastre da mais recente para a mais antiga. Para cada realização (bullet), marque tags de palavras-chave relacionadas — isso ajuda o algoritmo a escolher os bullets certos para cada vaga. Marque "sempre incluir" para conquistas que não podem ficar de fora nunca.
